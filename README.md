# my dvd archive 📀

everything i've watched lives here. scrolling through letterboxd one by one got boring so i lined them up on shelves like an old dvd cabinet. looks better

👉 **[brensvenka.github.io/DVD_Archive](https://brensvenka.github.io/DVD_Archive/)**

## what's inside

597 films and 102 reviews (some are one-liners, bear with me). click a poster to see my rating, when i watched it, who directed it, that kind of stuff. you can browse favorites, recent watches or by year. sort by rating and you'll find out what i hated too

## it updates itself

every morning github actions checks my letterboxd and adds whatever i watched. i watch movies, it does the rest. the bottom of the page shows the last sync

no setup, just open `index.html`

letterboxd: [brensvenka](https://letterboxd.com/brensvenka/)
